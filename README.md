# IBM-HR-Attrition-Analytics
# HR Workforce Analytics & Employee Attrition Dashboard

## 📌 Project Overview

This project presents an end-to-end **HR Workforce Analytics** solution focused on analyzing employee attrition, workforce composition, and employee-related factors associated with retention.

The project transforms raw employee data into actionable HR insights through:

- Data cleaning and preprocessing
- Exploratory data analysis
- SQL-based workforce analysis
- HR KPI development
- Attrition segmentation
- Interactive dashboard design
- Business-oriented insight generation

The objective is to provide HR teams and business stakeholders with a consolidated view of **workforce health and employee attrition patterns**.

---

## 🎯 Business Problem

Employee attrition can affect workforce stability, recruitment requirements, productivity, and organizational planning.

HR teams need to understand:

- How many employees are leaving?
- Which departments experience higher attrition?
- Which job roles have higher attrition?
- Is overtime associated with higher attrition?
- Which age groups show higher attrition?
- How does job satisfaction vary across employees?
- Which workforce segments require further investigation?

This project addresses these questions using employee-level HR data and presents the results through an executive-style dashboard.

# 🗂️ Dataset

The project uses the **IBM HR Employee Attrition dataset** containing employee-level demographic, employment, compensation, satisfaction, and attrition information.

### Dataset Information

- **Total records:** 1,470
- **Target variable:** `Attrition`
- **Attrition classes:** `Yes` / `No`

### Important attributes include

- Age
- Gender
- Department
- Job Role
- Monthly Income
- Years at Company
- Job Satisfaction
- OverTime
- Education
- Marital Status
- Job Level
- Environment Satisfaction
- Work-Life Balance
- Years in Current Role
- Years Since Last Promotion
